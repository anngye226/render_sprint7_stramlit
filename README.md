# render_sprint7_stramlit
titulo: Analisis Exploratotio de datos
##Descripción:
esta aplicación web permite realizar un análisis exploratorio de un conjunto de datos de anuncio de ventas

##Funcionalidad
la aplicación ofrece las siguientes funcionalidades
-Visualización de un histograma del kilometraje(odometer) de los vehículos
-Visualización de un gráfico de un gráfico de muestra la relación entre el precio y el kilometraje.
-interacción mediante botones para generar los gráficos de forma dinámica.

## Tecnología Utilizadas
Python
Pandas
Streamlit
Plotly Express
